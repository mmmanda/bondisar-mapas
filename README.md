# BondisAR · mapas sin internet

Mapas de cada provincia para la app BondisAR (un `.pmtiles` por provincia), recortados del mapa de
[OpenStreetMap](https://www.openstreetmap.org/copyright) que arma [Protomaps](https://protomaps.com).
Datos © colaboradores de OpenStreetMap, licencia ODbL.

Se bajan desde la app: `https://github.com/mmmanda/bondisar-mapas/releases/latest/download/<provincia>.pmtiles`.
La compilación (Actions → Mapas) los vuelve a armar una vez por mes o a mano.
